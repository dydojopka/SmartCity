# Материалы сдачи

## Состав проекта

- Шесть независимых сервисов с обязательными REST endpoints и собственными БД.
- Веб-интерфейс: регистрация, вход, пользователи, транспорт, парковки,
  заявки ЖКХ, датчики и счета с демонстрационной оплатой.
- Docker Compose, описание API, SQL/DBML и диаграммы всех шести БД.

## Передача преподавателю

1. Согласовать выбранные технологии: Python/FastAPI, SQLite, React и Docker Compose.
2. Закоммитить итоговую версию и опубликовать её в
   <https://github.com/dydojopka/SmartCity>.
3. Загрузить `smart-city/database-design.zip` на сервер.
4. Отправить преподавателю ссылку на репозиторий.

Фамилии участников и инструкция запуска указаны в README.
