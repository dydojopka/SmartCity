# Identity Service database

## `users`

Хранит учётные записи пользователей. `id` — UUID, который передаётся другим
сервисам только через JWT или HTTP API; внешних ключей в другие базы нет.

| Поле | Назначение |
|---|---|
| `id` | первичный ключ UUID |
| `email` | уникальный логин пользователя |
| `password_hash` | Argon2-хеш, пароль в открытом виде не сохраняется |
| `first_name`, `last_name` | данные публичного профиля |
| `role` | `USER`, `OPERATOR` или `ADMIN` |
| `is_active` | блокировка учётной записи без удаления |
| `created_at` | дата создания в UTC |

`email` имеет уникальное ограничение и индекс.
