## О проекте

Учебная экосистема из шести независимых микросервисов для управления городской
инфраструктурой. Backend разрабатывается на FastAPI, frontend - на React, каждый
сервис использует собственную SQLite-базу и взаимодействует с остальными только
по HTTP.

Исполняемый проект находится в каталоге [`smart-city`](smart-city/). Identity
и Utility Service уже реализованы; остальные обязательные предметные endpoints
разрабатываются участниками команды.

## Быстрый запуск

```bash
cd smart-city
cp .env.example .env
docker compose up --build
```
